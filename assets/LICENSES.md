# ZORO third-party and original assets

Every file ZORO ships that is not code is listed here (CLAUDE.md rule 11). A test
(`ios/Packages/ZoroDesign/Tests/ZoroDesignTests/AssetTests.swift`) parses this table and fails if a
file under `ios/Packages/ZoroDesign/Sources/ZoroDesign/Resources/` or `assets/AppIcon/` is missing
from it, or if a listed file does not exist.

Accepted licences: CC0 1.0 / public domain, SIL Open Font License 1.1, and the project's own original
work. Each licence was read on the source page on the retrieval date. No file is a trademark, a
store or app logo, an Apple or Siri asset, or AI-generated imagery.

## Licence evidence

- **Wikimedia Commons files**: each file page's licence section reads `{{self|cc-zero}}` or the
  Flickr-reviewed CC0 template, with "Creative Commons Zero, Public Domain Dedication" and
  "Attribution required: false". None of the files is in an AI-generated category. Files were fetched
  through Commons' own image server (`upload.wikimedia.org`), at a resolution Commons offers on the
  file page.
- **Poly Haven**: https://polyhaven.com/license states that all assets are CC0, original work of Poly
  Haven staff or donated by their authors, usable for any purpose including commercial products,
  with no attribution required.
- **Tiro Devanagari Hindi**: `OFL.txt` and `METADATA.pb` in the Google Fonts repository: SIL OFL 1.1,
  no Reserved Font Name; the font may be bundled with software provided the copyright notice and
  licence travel with it (they do: `TiroDevanagariHindi-OFL.txt` is in the same bundle).

Credits are not required by these licences; `ZoroArtwork.credit` carries them for the app's
acknowledgements screen.

## Considered and rejected

- *Skeins of Yarn (USA), ca. 1910*, Cooper Hewitt, on Commons: the page licenses the 1910 object as
  public domain but says nothing about the museum's photograph of it. Not shipped.
- Indigo garments by living designers (CC0 museum photos): the designs themselves may be protected.
  Not shipped.
